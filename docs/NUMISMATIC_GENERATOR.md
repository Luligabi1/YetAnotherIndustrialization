# Adding Numismatic Generator Items

**Numismatic Generator** uses emeralds to generate energy.

Other kinds of currencies can also be supported through [Data Maps](https://docs.neoforged.net/docs/resources/server/datamaps/). File is `data/yet_another_industrialization/data_maps/item/numismatic_generator_currency.json`. Use the following schema for each item:

```
"kubejs:my_cool_quest_modpack_coin_tier_9": {
    "eu_per_item": 262144
}
```
